🚀 คู่มือการเปิดใช้งานไฟล์ STEP AP203 และ STL ใน SOLIDWORKS

📦 วิธีที่ 1: เปิดไฟล์ STEP AP203 (.STEP) ใน SOLIDWORKS 2018+

1. ในโปรแกรม SOLIDWORKS ไปที่เมนู FILE > OPEN...

2. ในช่องประเภทไฟล์ (FILE TYPE) เลือก STEP AP203/214 (*.STEP, *.STP)

3. เลือกไฟล์ .STEP ที่ดาวน์โหลดจากระบบ

4. SOLIDWORKS จะ IMPORT โครงสร้าง B-REP SOLID เข้ามาเป็นเนื้อตันสมบูรณ์ 100% พร้อมใช้งานใน ASSEMBLY หรือสร้าง 2D DRAWING ต่อได้ทันที

🖨️ วิธีที่ 2: การใช้งานไฟล์ 3D STL (.STL) สำหรับ 3D PRINT & CNC

1. นำไฟล์ .STL เข้าโปรแกรม SLICER เช่น ULTIMAKER CURA, PRUSASLICER หรือ BAMBU STUDIO สำหรับงานพิมพ์ 3D PRINTING

2. หรือเปิดใน SOLIDWORKS โดยเลือกประเภทไฟล์เป็น STL (*.STL) เพื่อดูโครงสร้างตาข่าย 3D MESH
