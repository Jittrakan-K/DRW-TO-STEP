🚀 NASA CAD FLIGHT MANUAL // SOLIDWORKS & AP203 GUIDE

📦 วิธีที่ 1: การเปิดไฟล์ ISO 10303-21 STEP AP203 ใน SOLIDWORKS 2018-2026+

1. ในโปรแกรม SOLIDWORKS ไปที่เมนู File > Open...

2. ในช่องประเภทไฟล์ (Files of type) เลือก STEP AP203/214 (*.step, *.stp)

3. เลือกไฟล์ .step ที่ดาวน์โหลดจากระบบ

4. SOLIDWORKS จะ Import โครงสร้าง B-Rep Manifold Solid เข้ามาเป็นเนื้อตันสมบูรณ์ 100% ไร้รอยแยกผิว พร้อมใช้งานใน Assembly หรือสร้าง 2D Drawing ได้ทันที

⚙️ วิธีที่ 2: รันโค้ด SolidWorks VBA Macro สร้าง Feature Tree

1. ใน SOLIDWORKS กดเมนู Tools > Macro > Run... (หรือกด Play บนแถบ Macro)

2. เลือกไฟล์ .vba ที่บันทึกไว้ หรือวางโค้ดใน VBA Editor (Alt + F11)

3. SolidWorks จะวาด Sketch และสร้าง Boss-Extrude / Cut-Extrude แบบ Parametric อัตโนมัติใน 1 วินาที

🖨️ วิธีที่ 3: การใช้งานไฟล์ 3D STL (.stl) สำหรับ 3D Print & CNC

1. นำไฟล์ .stl เข้าโปรแกรม Slicer (Bambu Studio, PrusaSlicer, Ultimaker Cura) เพื่อเตรียมพิมพ์ 3 มิติ

2. หรือเปิดใน CAM Software สำหรับการเขียนทางเดินมีดกัดงาน CNC (Milling/Turning)

🔑 GOOGLE GEMINI VISION // FLIGHT CREDENTIALS

ระบบจะเชื่อมต่อ Google Gemini 1.5 Flash Vision API โดยตรงจากเบราว์เซอร์ของคุณ เพื่อวิเคราะห์คำอธิบายภาษาธรรมชาติและรูปภาพสเก็ตช์อ้างอิง แล้วสกัดเป็นพารามิเตอร์ 3D CAD

🔒 CLIENT-SIDE SECURITY 100%: API Key ของคุณจะถูกบันทึกไว้ใน LocalStorage บนเบราว์เซอร์เครื่องของคุณเท่านั้น ไม่มีการส่งไปเก็บไว้บนเซิร์ฟเวอร์ภายนอกใด ๆ ทั้งสิ้น
