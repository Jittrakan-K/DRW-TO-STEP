วิธีที่ 1: เปิดไฟล์ .sldprt โดยตรง (เร็วที่สุด)

1. กดปุ่ม "ดาวน์โหลด .sldprt" จากหน้าเว็บ

2. ดับเบิลคลิกไฟล์ AA-14.sldprt เพื่อเปิดใน SOLIDWORKS 2018 ได้ทันที

3. ไฟล์จะแสดงเป็นชิ้นงาน Part ดั้งเดิมของ SolidWorks พร้อมใช้งานต่อใน Assembly หรือ Drawing 2D

📦

วิธีที่ 2: เปิดไฟล์ STEP AP203 (.step)

1. ในโปรแกรม SolidWorks ไปที่เมนู File > Open...

2. ที่ช่องประเภทไฟล์เลือก STEP AP203/214 (*.step, *.stp)

3. เลือกไฟล์ AA-14_AP203.step

4. SolidWorks จะ Import โครงสร้าง 3D B-Rep Manifold Solid เข้ามาเป็นเนื้อตัน (Solid Body) ทันที

⚡

วิธีที่ 3: รัน SolidWorks Macro (.vba) เพื่อสร้าง Feature Tree

1. ใน SolidWorks เปิดเอกสารชิ้นงานใหม่ (File > New > Part)

2. ไปที่เมนู Tools > Macro > Run... (หรือกดคีย์ลัด Alt+F11)

3. เลือกไฟล์ AA-14_SolidWorks_Macro.vba

4. โปรแกรมจะวาด Sketch จริง และสร้าง Revolve, Cut-Extrude, Chamfer ใน Feature Tree ให้อัตโนมัติ สามารถเข้าไปแก้ไขตัวเลขขนาดเดิมได้ 100%!

⚙️

วิธีที่ 4: สั่งสร้างผ่านไฟล์สคริปต์อัตโนมัติในเครื่อง

หากคุณเปิดระบบในโฟลเดอร์โครงการ สามารถดับเบิลคลิกไฟล์ generate_sldprt.bat เพื่อสั่งให้ SolidWorks 2018 ในเครื่องเปิดขึ้นมาสร้างและเซฟไฟล์ .sldprt ให้โดยอัตโนมัติ
