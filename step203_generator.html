💡 ทำไมต้องใช้ SolidWorks Macro?
ไฟล์ STEP AP203 ทั่วไปจะเปิดเป็น Imported Body (ก้อนทึบไม่มีประวัติ Feature)
แต่เมื่อรันโค้ด Macro นี้ใน SolidWorks ระบบจะ วาด Sketch จริง และสร้าง Feature Tree (Boss-Extrude, Cut-Extrude) ใน SolidWorks โดยตรง คุณจะสามารถคลิก Edit Feature / Edit Sketch เพื่อแก้ไขขนาดใน SolidWorks ได้ 100%!

1
เปิดโปรแกรม SolidWorks แล้วสร้าง Part ใหม่ (New Part)
2
ไปที่เมนู Tools > Macro > New (หรือกด Alt + F11 เพื่อเปิด VBA Editor)
3
คัดลอกโค้ดด้านล่างนี้ไปวางทับใน Macro แล้วกดปุ่ม Run (▶) ได้ทันที!
